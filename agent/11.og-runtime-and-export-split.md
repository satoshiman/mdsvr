# 🚀 Code Agent Guide: OG Runtime Generation & Export Split

Hướng dẫn chi tiết để Code Agent thực hiện 2 tính năng:
1. **Dev mode** (`mdsvr .`) – sinh OG image **on-demand** (runtime), lưu vào `<rootDir>/public/og/`
2. **Tách export** thành 3 flag riêng:
   - `-eo` / `--export-og` – chỉ gen OG images (có skip existing)
   - `-es` / `--export-static` – chỉ export static HTML
   - `-e` / `--export` – export cả 2 (static + OG)

---

## 📋 Tổng quan thay đổi

| Flag | Hành vi |
|---|---|
| `mdsvr .` | Dev server + serve `/public/og/*.jpg` on-demand, gen & cache vào `<rootDir>/public/og/` |
| `mdsvr . -eo` | Copy `<rootDir>/public/og/` → `_html/public/og/`, sau đó gen OG cho các page chưa có |
| `mdsvr . -es` | Export static HTML sang `_html/public/` (không gen OG) |
| `mdsvr . -e` | Export static HTML **và** gen OG (tương đương `-es` + `-eo`) |

---

## 🎯 Task 1: Dev mode – OG runtime generation

### Mục đích
Khi `mdsvr .` đang chạy, cho phép browser request ảnh OG tại `/public/og/<path>/index.jpg`.
- Nếu file đã có trong `<rootDir>/public/og/` → serve file đó
- Nếu chưa có → tự động generate → lưu cache → trả về ảnh

### Files affected
- 📝 **Modify:** `src/server.ts` (hoặc `src/router.ts` – nơi xử lý HTTP routes)

### Cần tìm hiểu trước
Tìm trong `src/server.ts` hoặc `src/router.ts` route handler cho static files / `/public/` để thêm handler mới **trước** existing static handler.

### Logic cần thêm

```typescript
// Trong route handler, thêm TRƯỚC handler static files thông thường:
if (urlPath.startsWith("/public/og/") && (urlPath.endsWith(".jpg") || urlPath.endsWith(".png"))) {
  const ogCacheDir = path.join(rootDir, "public", "og");
  const filePath = path.join(rootDir, urlPath); // rootDir + /public/og/xxx/index.jpg

  // 1. Check cache trên disk
  try {
    const data = await fs.readFile(filePath);
    const ext = path.extname(filePath).slice(1); // jpg hoặc png
    res.setHeader("Content-Type", ext === "png" ? "image/png" : "image/jpeg");
    res.end(data);
    return;
  } catch {
    // File chưa tồn tại, tiếp tục gen
  }

  // 2. Xác định urlPath của page từ OG path
  // /public/og/getting-started/index.jpg → page urlPath = /getting-started/
  // /public/og/index.jpg → page urlPath = /
  const pagePath = urlPath
    .replace(/^\/public\/og/, "")   // bỏ /public/og
    .replace(/\/index\.(jpg|png)$/, "/"); // bỏ /index.jpg cuối

  // 3. Load settings + đọc nội dung markdown tương ứng
  // Dùng buildOgDataForPath() – helper cần tạo trong server
  const ogData = await buildOgDataForPath(pagePath, rootDir, settings);
  if (!ogData) {
    res.statusCode = 404;
    res.end("Not found");
    return;
  }

  // 4. Generate OG image
  const format = settings.seo.og?.imageFormat || "jpg";
  const { generateOgImage } = await import("./og/index.js");
  const result = await generateOgImage(ogData, {
    outputPath: filePath, // tự động mkdir recursive bên trong
    format,
    quality: 85,
  });

  if (result.success) {
    const data = await fs.readFile(filePath);
    res.setHeader("Content-Type", format === "png" ? "image/png" : "image/jpeg");
    res.end(data);
  } else {
    res.statusCode = 500;
    res.end("OG generation failed");
  }
  return;
}
```

### Helper `buildOgDataForPath()`
Cần thêm function này trong server module (hoặc import từ og module):

```typescript
async function buildOgDataForPath(
  pagePath: string, // e.g., "/getting-started/" hay "/"
  rootDir: string,
  settings: Settings,
): Promise<OgImageData | null> {
  // Map pagePath → markdown file path
  // "/" → README.md
  // "/getting-started/" → getting-started/README.md
  // "/getting-started/install" → getting-started/install.md
  const { findMarkdownFileForPath } = await import("./directory.js"); // hoặc tạo util mới
  // Fallback: dùng site title nếu không tìm được file
  let title = settings.site.title;
  let description: string | undefined;

  const mdFile = await resolveMarkdownFile(pagePath, rootDir);
  if (mdFile) {
    const content = await fs.readFile(mdFile, "utf-8");
    const { renderMarkdown } = await import("./renderer/markdown.js");
    const result = renderMarkdown(content, settings);
    title = (result.frontmatter.title as string) || extractH1(content) || title;
    description = result.frontmatter.description as string | undefined;
  }

  return {
    title,
    description,
    siteName: settings.site.title,
    urlPath: pagePath,
    accentColor: settings.appearance.accentColor,
    fontFamily: settings.seo.og?.fontFamily || "Inter",
    backgroundColor: settings.seo.og?.colors?.background || "#0a0a0f",
    textColor: settings.seo.og?.colors?.text || "#ffffff",
  };
}

async function resolveMarkdownFile(pagePath: string, rootDir: string): Promise<string | null> {
  // pagePath examples: "/", "/guide/", "/guide/install"
  const clean = pagePath.replace(/^\//, "").replace(/\/$/, ""); // "guide/install"
  const candidates = clean === ""
    ? ["README.md", "readme.md", "index.md"]
    : [
        `${clean}/README.md`,
        `${clean}/readme.md`,
        `${clean}.md`,
      ];

  for (const rel of candidates) {
    const full = path.join(rootDir, rel);
    try {
      await fs.access(full);
      return full;
    } catch {}
  }
  return null;
}

function extractH1(content: string): string | null {
  const m = content.match(/^#\s+(.+)$/m);
  return m ? m[1].trim() : null;
}
```

### Lưu ý
- OG chỉ được gen khi `settings.seo.og?.enabled === true`
- Nếu OG disabled → trả về 404 (hoặc redirect về default OG image)
- `public/og/` là **cache directory** trong source tree, nên cần thêm vào `.gitignore` (optional, tùy user)
- Performance: Font download có thể chậm lần đầu – font cache (`fontCache` Map) trong `generator.ts` đã tồn tại, dùng lại được

### Implement `exportOgImages()`

```typescript
export async function exportOgImages(options: ExportOgOptions): Promise<void> {
  const {
    rootDir,
    outputDir,
    settings,
    silent = false,
    skipExisting = true,
    copyFromSource = true,
  } = options;

  const absRootDir = path.resolve(rootDir);
  const absOutputDir = path.resolve(outputDir);
  const ogOutputDir = path.join(absOutputDir, "public", "og");

  await fs.mkdir(ogOutputDir, { recursive: true });

  if (!silent) {
    console.log(`\n  🖼️  Exporting OG images`);
    console.log(`  From: ${absRootDir}`);
    console.log(`  To:   ${ogOutputDir}\n`);
  }

  // Step 1: Copy existing OG images from <rootDir>/public/og/ (runtime cache)
  if (copyFromSource) {
    const sourceOgDir = path.join(absRootDir, "public", "og");
    try {
      await fs.access(sourceOgDir);
      await copyOgCache(sourceOgDir, ogOutputDir, silent);
    } catch {
      // sourceOgDir không tồn tại, bỏ qua
    }
  }

  // Step 2: Collect all pages
  const pageInfos: PageInfo[] = [];
  await collectPageInfos(absRootDir, absRootDir, settings, pageInfos);

  // Step 3: Gen OG cho các page chưa có
  const format = settings.seo.og?.imageFormat || "jpg";
  const ogSettings = settings.seo.og;
  let generatedCount = 0;
  let skippedCount = 0;
  let failedCount = 0;

  for (const pageInfo of pageInfos) {
    const ogImagePath = getOgImagePath(
      pageInfo.urlPath,
      ogOutputDir,
      format,
      settings.generate.basePath,
    );

    // Skip nếu đã tồn tại
    if (skipExisting) {
      try {
        await fs.access(ogImagePath);
        skippedCount++;
        continue;
      } catch {
        // Chưa có, tiến hành gen
      }
    }

    const ogData: OgImageData = {
      title: pageInfo.title,
      description: pageInfo.description,
      siteName: settings.site.title,
      urlPath: pageInfo.urlPath,
      accentColor: settings.appearance.accentColor,
      fontFamily: ogSettings?.fontFamily || "Inter",
      backgroundColor: ogSettings?.colors?.background || "#0a0a0f",
      textColor: ogSettings?.colors?.text || "#ffffff",
    };

    const result = await generateOgImage(ogData, {
      outputPath: ogImagePath,
      format,
      quality: 85,
    });

    if (result.success) {
      generatedCount++;
      if (!silent) {
        const displayPath = path.relative(absOutputDir, ogImagePath);
        console.log(`  ✓ OG: ${displayPath}`);
      }
    } else {
      failedCount++;
      if (!silent) {
        console.log(`  ✗ OG failed: ${pageInfo.urlPath} (${result.error})`);
      }
    }
  }

  if (!silent) {
    console.log(
      `\n  ✔ OG: ${generatedCount} generated, ${skippedCount} skipped, ${failedCount} failed\n`,
    );
  }
}
```

### Helper `copyOgCache()` (thêm vào static-export.ts)

```typescript
async function copyOgCache(
  srcDir: string,
  destDir: string,
  silent: boolean,
): Promise<void> {
  const entries = await fs.readdir(srcDir, { withFileTypes: true });
  for (const entry of entries) {
    const src = path.join(srcDir, entry.name);
    const dest = path.join(destDir, entry.name);
    if (entry.isDirectory()) {
      await fs.mkdir(dest, { recursive: true });
      await copyOgCache(src, dest, silent);
    } else if (entry.isFile()) {
      const ext = path.extname(entry.name).toLowerCase();
      if (ext === ".jpg" || ext === ".jpeg" || ext === ".png") {
        await fs.mkdir(path.dirname(dest), { recursive: true });
        await fs.copyFile(src, dest);
        if (!silent) {
          console.log(`  ✓ Copied OG cache: ${entry.name}`);
        }
      }
    }
  }
}
```

### Helper `collectPageInfos()` (thu thập page list mà không render HTML)

```typescript
async function collectPageInfos(
  dirPath: string,
  rootDir: string,
  settings: Settings,
  pageInfos: PageInfo[],
): Promise<void> {
  const entries = await fs.readdir(dirPath, { withFileTypes: true });

  for (const entry of entries) {
    const fullPath = path.join(dirPath, entry.name);

    if (isHidden(entry.name, settings)) continue;

    if (entry.isDirectory()) {
      if (!isStaticFolder(entry.name, settings)) {
        await collectPageInfos(fullPath, rootDir, settings, pageInfos);
      }
    } else if (entry.isFile()) {
      const ext = path.extname(entry.name).toLowerCase();
      if (isBlocked(ext, settings)) continue;

      if (ext === ".md" || (ext === ".mdx" && settings.mdx.enabled)) {
        const content = await fs.readFile(fullPath, "utf-8");
        const baseName = entry.name.replace(/\.(md|mdx)$/, "");
        const baseNameLower = baseName.toLowerCase();

        let urlPath: string;
        if (baseNameLower === "readme") {
          let rawUrlPath = "/" + path.relative(rootDir, dirPath).replace(/\\/g, "/");
          if (rawUrlPath !== "/") rawUrlPath += "/";
          urlPath = rawUrlPath;
        } else {
          urlPath =
            "/" +
            path.relative(rootDir, fullPath).replace(/\\/g, "/").replace(/\.(md|mdx)$/, "");
        }

        // Quick frontmatter parse (không cần full render)
        const { renderMarkdown } = await import("../renderer/markdown.js");
        const result = renderMarkdown(content, settings);
        const title =
          (result.frontmatter.title as string) ||
          extractFirstHeading(content) ||
          humanizeFilename(baseName);

        pageInfos.push({
          urlPath,
          outputPath: "", // không cần outputPath cho OG-only
          title,
          description: result.frontmatter.description as string | undefined,
        });
      }
    }
  }
}
```

## ⚠️ Edge Cases

- **OG disabled** (`settings.seo.og.enabled = false`): runtime handler trả 404, `-eo` in warning và exit
- **Font download timeout**: đã có retry/cache trong `src/og/generator.ts` – không cần thêm
- **`public/og/` rỗng** khi chạy `-eo`: vẫn chạy bình thường, chỉ gen tất cả từ đầu
- **Concurrency**: Runtime gen tuần tự (không race condition vì mỗi request gen file riêng)
- **`basePath` setting**: `getOgImagePath()` đã handle `basePath` – dùng lại như hiện tại

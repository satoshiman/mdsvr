# Fix: Mermaid không đổi theme khi toggle dark/light

## Root cause

`toggleTheme()` và system theme listener chỉ set `data-theme` attribute trên `<html>`.
Mermaid đã render SVG từ trước — không tự re-render khi theme thay đổi.

## Fix — `src/template/index.ts`

### 1. Sửa Mermaid init script (đã có từ Feat-add-mermaid)

Expose `mermaid` ra `window` để `toggleTheme` có thể gọi sau:

```ts
// ❌ Hiện tại
<script type="module">
  import mermaid from 'https://cdn.jsdelivr.net/npm/mermaid@11/dist/mermaid.esm.min.mjs';
  const isDark = document.documentElement.getAttribute('data-theme') === 'dark';
  mermaid.initialize({ startOnLoad: true, theme: isDark ? 'dark' : 'default' });
</script>

// ✅ Fix — expose ra window
<script type="module">
  import mermaid from 'https://cdn.jsdelivr.net/npm/mermaid@11/dist/mermaid.esm.min.mjs';
  const isDark = document.documentElement.getAttribute('data-theme') === 'dark';
  mermaid.initialize({ startOnLoad: true, theme: isDark ? 'dark' : 'default' });
  window.__mermaid = mermaid;
</script>
```

### 2. Thêm hàm `rerenderMermaid` và gọi nó ở 2 chỗ

Thêm hàm này vào `<script>` block hiện có (cùng chỗ với `toggleTheme`):

```js
function rerenderMermaid(theme) {
  if (!window.__mermaid) return;
  var diagrams = document.querySelectorAll(".mermaid");
  if (!diagrams.length) return;

  // Restore original source trước khi re-render
  diagrams.forEach(function (el) {
    var src = el.getAttribute("data-mermaid-src");
    if (src) el.textContent = src;
    else {
      // Lần đầu: lưu lại source gốc
      el.setAttribute("data-mermaid-src", el.textContent);
    }
    el.removeAttribute("data-processed");
  });

  window.__mermaid.initialize({
    startOnLoad: false,
    theme: theme === "dark" ? "dark" : "default",
  });
  window.__mermaid.run({ nodes: diagrams });
}
```

### 3. Gọi `rerenderMermaid` trong `toggleTheme`

```js
// ❌ Hiện tại
function toggleTheme() {
  var current = document.documentElement.getAttribute("data-theme");
  var next = current === "dark" ? "light" : "dark";
  document.documentElement.setAttribute("data-theme", next);
  localStorage.setItem("theme", next);
}

// ✅ Fix
function toggleTheme() {
  var current = document.documentElement.getAttribute("data-theme");
  var next = current === "dark" ? "light" : "dark";
  document.documentElement.setAttribute("data-theme", next);
  localStorage.setItem("theme", next);
  rerenderMermaid(next); // thêm dòng này
}
```

### 4. Gọi `rerenderMermaid` trong system theme listener

```js
// ❌ Hiện tại
mediaQuery.addListener(function (e) {
  if (
    localStorage.getItem("theme") === "system" ||
    !localStorage.getItem("theme")
  ) {
    document.documentElement.setAttribute(
      "data-theme",
      e.matches ? "dark" : "light",
    );
  }
});

// ✅ Fix
mediaQuery.addListener(function (e) {
  if (
    localStorage.getItem("theme") === "system" ||
    !localStorage.getItem("theme")
  ) {
    var next = e.matches ? "dark" : "light";
    document.documentElement.setAttribute("data-theme", next);
    rerenderMermaid(next); // thêm dòng này
  }
});
```

## Tóm tắt các chỗ sửa trong `src/template/index.ts`

| Chỗ                              | Thay đổi                          |
| -------------------------------- | --------------------------------- |
| Mermaid `<script type="module">` | Thêm `window.__mermaid = mermaid` |
| `<script>` block chính           | Thêm hàm `rerenderMermaid`        |
| `toggleTheme()`                  | Thêm `rerenderMermaid(next)`      |
| `mediaQuery.addListener`         | Thêm `rerenderMermaid(next)`      |

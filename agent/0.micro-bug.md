## OG Image Format: JPG → PNG Trade-off

- [ ] **Đánh giá chuyển OG image sang PNG**

  |                       | JPG (hiện tại)                                                  | PNG                                                         |
  | --------------------- | --------------------------------------------------------------- | ----------------------------------------------------------- |
  | **Package**           | cần `sharp` (native binding)                                    | dùng `@resvg/resvg-js` hoặc `canvas` thuần, bỏ được `sharp` |
  | **Node.js version**   | `sharp` yêu cầu Node ≥ 18, prebuilt binding per platform        | PNG lib nhẹ hơn, ít ràng buộc version hơn                   |
  | **Docker image**      | phải build `sharp` native → image nặng hơn, cần `python`/`make` | bỏ native dep → Docker image nhỏ hơn, build nhanh hơn       |
  | **Chi phí render**    | JPEG encode nhanh hơn                                           | PNG encode chậm hơn ~20-40%, tốn RAM hơn với ảnh lớn        |
  | **Dung lượng static** | nhỏ hơn (lossy)                                                 | lớn hơn ~2-4x (lossless) → tăng repo size & bandwidth       |
  | **Chất lượng**        | artifact ở text/logo                                            | lossless, text sắc nét hơn                                  |

  **Kết luận tạm**: PNG tốt hơn về chất lượng & infra đơn giản hơn, nhưng đánh đổi dung lượng static tăng đáng kể. Cần đo thực tế trước khi quyết định.

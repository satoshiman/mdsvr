# Markdown Validation Feature

> Thêm tính năng validate markdown file với kiểm tra internal link và structure validation.

---

## Overview

Thêm module validation cho markdown files với các tính năng:
- **Internal link validation**: Kiểm tra các link nội bộ có tồn tại hay không
- **Autofix**: Tự động sửa các link bị sai dựa trên fuzzy matching
- **Structure validation**: Kiểm tra heading hierarchy

---

## Implementation

### 1. Create Validation Module

**File**: `src/validator/index.ts`

**Interfaces**:
```typescript
export interface ValidationError {
  file: string;
  line: number;
  type: "broken-link" | "invalid-structure" | "missing-frontmatter" | "heading-hierarchy";
  message: string;
  suggestion?: string;
  autofix?: string;
  original?: string;
}

export interface ValidationResult {
  valid: boolean;
  errors: ValidationError[];
  fixed: number;
}

export interface ValidateMarkdownOptions {
  rootDir: string;
  autofix?: boolean;
  checkLinks?: boolean;
  checkStructure?: boolean;
}
```

**Key Functions**:

- `extractInternalLinks()`: Extract all internal markdown links from content
- `resolveLink()`: Resolve link relative to the file it's in
- `validateInternalLinks()`: Check if internal links exist
- `findSimilarFile()`: Find similar files using fuzzy matching (Levenshtein distance)
- `validateStructure()`: Check heading hierarchy
- `getAllMarkdownFiles()`: Recursively scan directory for .md/.mdx files
- `validateMarkdown()`: Main validation function

### 2. Add CLI Flags

**File**: `src/cli.ts`

**New flags**:
- `--validate-md`: Validate all markdown files and exit
- `--autofix`: Auto-fix markdown validation errors (use with --validate-md)

**Updated ParsedArgs interface**:
```typescript
interface ParsedArgs {
  // ... existing fields
  validateMd: boolean;
  autofix: boolean;
}
```

**Handler**:
```typescript
// Handle --validate-md
if (args.validateMd) {
  try {
    const { validateMarkdown } = await import("./validator/index.js");
    const result = await validateMarkdown({
      rootDir: absoluteDir,
      autofix: args.autofix,
      checkLinks: true,
      checkStructure: true,
    });

    if (result.valid) {
      console.log(`\n  ✔ All markdown files are valid\n`);
      process.exit(0);
    } else {
      console.log(`\n  ✖ Found ${result.errors.length} validation error(s):`);
      result.errors.forEach((e) => {
        console.log(`    - ${e.file}:${e.line} - ${e.message}`);
        if (e.suggestion) {
          console.log(`      💡 ${e.suggestion}`);
        }
      });
      if (args.autofix && result.fixed > 0) {
        console.log(`\n  ✔ Auto-fixed ${result.fixed} error(s)\n`);
      }
      console.log();
      process.exit(1);
    }
  } catch (err) {
    console.error("Error:", err instanceof Error ? err.message : err);
    process.exit(1);
  }
}
```

## Features

### Internal Link Validation

- Extracts all markdown links: `[text](path)`
- Skips external links (http://, https://, //)
- Skips protocol links (mailto:, tel:, etc.)
- Resolves relative and absolute paths
- Checks if target file exists
- Skips self-links (links to the same file)

### Autofix

- Uses fuzzy matching (Levenshtein distance) to find similar filenames
- Suggests corrections for typos
- Automatically replaces broken links when `--autofix` is enabled
- Example: `traget.md` → `target.md`

### Structure Validation

- Checks heading hierarchy (no skipping levels like H1 → H3)
- Frontmatter check is optional (not enforced)
- Detects invalid heading jumps

## Implementation Details

### Fuzzy Matching Algorithm

Uses Levenshtein distance to calculate string similarity:
- Score > 0.6 considered a match
- Exact match with different case also detected
- Searches in the same directory as the broken link

### Link Resolution Logic

1. If link starts with `/`: absolute path from root
2. If link starts with `#`: anchor (same file)
3. Otherwise: relative path from file directory
4. Remove anchor if present
5. Add `.md` extension if missing
6. Check if file exists

### File Scanning

- Recursively walks directory tree
- Skips hidden files (starting with `.`)
- Skips `_mdsvr` directory
- Skips `node_modules`
- Includes both `.md` and `.mdx` files

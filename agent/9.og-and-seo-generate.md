# OG Image Generation & SEO Enhancement Plan

## Overview

Implement automatic OG image generation and enhance SEO tag creation with smart fallbacks.

## Requirements

### 1. Enhanced SEO Tag Generation

- **Priority**: Frontmatter > Auto-generated content
- **Title Fallback**: First H1 heading from markdown content
- **Description Fallback**: First paragraph/text from markdown content

### 2. OG Image Generation Modes

- **Serve Mode** (`mdsvr ./docs`):
  - Don't generate OG images unless explicitly requested
  - Use existing OG tags with default image if configured
- **Export Mode** (`mdsvr export`):
  - Always generate OG images for all markdown files
  - Export to `/public/assets/og/<path-to-docs>.jpg`

### 3. OG Image Generation Stack

- **Satori**: Convert JSX/CSS to SVG
- **Resvg**: Convert SVG to JPG/PNG
- Add as dev dependencies

## Implementation Plan

### Phase 1: Dependencies & Setup

1. Add dev dependencies:

   ```bash
   npm install --save-dev satori @resvg/resvg
   ```

2. Create OG template system:
   - `src/og/template.tsx` - OG image JSX template
   - `src/og/generator.ts` - OG image generation logic
   - `src/og/types.ts` - OG data types

### Phase 2: Enhanced SEO Tag Logic

1. Update `src/template/seo.ts`:
   - Add function to extract title from markdown (first H1)
   - Add function to extract description from markdown (first paragraph)
   - Modify `buildSeoTags()` to use smart fallbacks

2. Update `src/renderer/markdown.ts`:
   - Export AST or parsed content for SEO extraction
   - Add functions to extract headings and paragraphs

### Phase 3: OG Image Generation

1. Create OG image generator:

   ```typescript
   // src/og/generator.ts
   export async function generateOgImage(
     data: OgImageData,
     outputPath: string,
   ): Promise<void>;
   ```

2. OG template design:
   - Title (truncated if too long)
   - Description (truncated if too long)
   - Site logo/branding
   - Background gradient/pattern
   - URL path

3. Update static export:
   - Generate OG images during export process
   - Create `/public/assets/og/` directory structure
   - Update OG image URLs in SEO tags

### Phase 4: Settings Integration

1. Add OG settings to schema:

   ```json
   {
     "og": {
       "enabled": true,
       "template": "default", // future: multiple templates
       "imageFormat": "jpg", // jpg, png
       "generateOnServe": false,
       "fontFamily": "Inter",
       "colors": {
         "background": "#ffffff",
         "text": "#000000",
         "accent": "#0969da"
       }
     }
   }
   ```

2. Update settings schema and defaults

### Phase 5: Integration Points

1. **Server Mode** (`src/server.ts`):
   - Skip OG generation unless `og.generateOnServe = true`
   - Use existing SEO tag logic

2. **Export Mode** (`src/generators/static-export.ts`):
   - Add OG image generation step
   - Generate after processing all markdown files
   - Update SEO tags with generated image URLs

3. **Template Integration** (`src/template/index.ts`):
   - Update SEO data with generated image paths
   - Handle base path for OG images

## Technical Details

### OG Image Specifications

- **Dimensions**: 1200x630px (Facebook/LinkedIn optimal)
- **Format**: JPG (smaller file size) or PNG (better quality)
- **Quality**: 85% compression for JPG
- **Font**: Inter (or system font fallback)

### File Structure

```
public/assets/og/
├── index.jpg                    # homepage OG
├── getting-started/
│   └── index.jpg               # /getting-started/ OG
├── guides/
│   ├── installation.jpg        # /guides/installation OG
│   └── configuration.jpg       # /guides/configuration OG
└── ...
```

### URL Mapping

- Markdown file: `/docs/guides/setup.md`
- OG image: `/public/assets/og/guides/setup.jpg`
- OG URL in meta tag: `/og/guides/setup.jpg`

## Edge Cases & Considerations

### Content Extraction

- Handle markdown files without H1 headings
- Handle very long titles/descriptions (truncate appropriately)
- Handle special characters and encoding

### File System

- Handle nested directory structures
- Handle filename conflicts
- Clean up old OG images when files are deleted

### Performance

- Batch process OG generation
- Cache generated images
- Skip regeneration if content unchanged

### Error Handling

- Graceful fallback if OG generation fails
- Log warnings for missing fonts/assets
- Continue export process if individual OG fails

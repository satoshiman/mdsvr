# 🚀 Code Agent Guide: OG Runtime Generation

Hướng dẫn chi tiết để Code Agent thực hiện tính năng:

**Dev mode** (`mdsvr .`) – sinh OG image **on-demand** (runtime), lưu vào `<rootDir>/public/og/`

---

## 🎯 Task: Dev mode – OG runtime generation

### Mục đích

Khi `mdsvr .` đang chạy, cho phép browser request ảnh OG tại `/public/og/<path>/index.jpg`.

- Nếu file đã có trong `<rootDir>/public/og/` → serve file đó
- Nếu chưa có → tự động generate → lưu cache → trả về ảnh

### Files affected

- 📝 **Modify:** `src/server.ts` (hoặc `src/router.ts` – nơi xử lý HTTP routes)

### Cần tìm hiểu trước

Tìm trong `src/server.ts` hoặc `src/router.ts` route handler cho static files / `/public/` để thêm handler mới **trước** existing static handler.

### Logic cần thêm

```typescript
// Trong route handler, thêm TRƯỚC handler static files thông thường:
if (
  urlPath.startsWith("/public/og/") &&
  (urlPath.endsWith(".jpg") || urlPath.endsWith(".png"))
) {
  const ogCacheDir = path.join(rootDir, "public", "og");
  const filePath = path.join(rootDir, urlPath); // rootDir + /public/og/xxx/index.jpg

  // 1. Check cache trên disk
  try {
    const data = await fs.readFile(filePath);
    const ext = path.extname(filePath).slice(1); // jpg hoặc png
    res.setHeader("Content-Type", ext === "png" ? "image/png" : "image/jpeg");
    res.end(data);
    return;
  } catch {
    // File chưa tồn tại, tiếp tục gen
  }

  // 2. Xác định urlPath của page từ OG path
  // /public/og/getting-started/index.jpg → page urlPath = /getting-started/
  // /public/og/index.jpg → page urlPath = /
  const pagePath = urlPath
    .replace(/^\/public\/og/, "") // bỏ /public/og
    .replace(/\/index\.(jpg|png)$/, "/"); // bỏ /index.jpg cuối

  // 3. Load settings + đọc nội dung markdown tương ứng
  // Dùng buildOgDataForPath() – helper cần tạo trong server
  const ogData = await buildOgDataForPath(pagePath, rootDir, settings);
  if (!ogData) {
    res.statusCode = 404;
    res.end("Not found");
    return;
  }

  // 4. Generate OG image
  const format = settings.seo.og?.imageFormat || "jpg";
  const { generateOgImage } = await import("./og/index.js");
  const result = await generateOgImage(ogData, {
    outputPath: filePath, // tự động mkdir recursive bên trong
    format,
    quality: 85,
  });

  if (result.success) {
    const data = await fs.readFile(filePath);
    res.setHeader(
      "Content-Type",
      format === "png" ? "image/png" : "image/jpeg",
    );
    res.end(data);
  } else {
    res.statusCode = 500;
    res.end("OG generation failed");
  }
  return;
}
```

### Helper `buildOgDataForPath()`

Cần thêm function này trong server module (hoặc import từ og module):

```typescript
async function buildOgDataForPath(
  pagePath: string, // e.g., "/getting-started/" hay "/"
  rootDir: string,
  settings: Settings,
): Promise<OgImageData | null> {
  // Map pagePath → markdown file path
  // "/" → README.md
  // "/getting-started/" → getting-started/README.md
  // "/getting-started/install" → getting-started/install.md
  const { findMarkdownFileForPath } = await import("./directory.js"); // hoặc tạo util mới
  // Fallback: dùng site title nếu không tìm được file
  let title = settings.site.title;
  let description: string | undefined;

  const mdFile = await resolveMarkdownFile(pagePath, rootDir);
  if (mdFile) {
    const content = await fs.readFile(mdFile, "utf-8");
    const { renderMarkdown } = await import("./renderer/markdown.js");
    const result = renderMarkdown(content, settings);
    title = (result.frontmatter.title as string) || extractH1(content) || title;
    description = result.frontmatter.description as string | undefined;
  }

  return {
    title,
    description,
    siteName: settings.site.title,
    urlPath: pagePath,
    accentColor: settings.appearance.accentColor,
    fontFamily: settings.seo.og?.fontFamily || "Inter",
    backgroundColor: settings.seo.og?.colors?.background || "#0a0a0f",
    textColor: settings.seo.og?.colors?.text || "#ffffff",
  };
}

async function resolveMarkdownFile(
  pagePath: string,
  rootDir: string,
): Promise<string | null> {
  // pagePath examples: "/", "/guide/", "/guide/install"
  const clean = pagePath.replace(/^\//, "").replace(/\/$/, ""); // "guide/install"
  const candidates =
    clean === ""
      ? ["README.md", "readme.md", "index.md"]
      : [`${clean}/README.md`, `${clean}/readme.md`, `${clean}.md`];

  for (const rel of candidates) {
    const full = path.join(rootDir, rel);
    try {
      await fs.access(full);
      return full;
    } catch {}
  }
  return null;
}

function extractH1(content: string): string | null {
  const m = content.match(/^#\s+(.+)$/m);
  return m ? m[1].trim() : null;
}
```

### Lưu ý

- OG chỉ được gen khi `settings.seo.og?.enabled === true`
- Nếu OG disabled → trả về 404 (hoặc redirect về default OG image)
- `public/og/` là **cache directory** trong source tree, nên cần thêm vào `.gitignore` (optional, tùy user)
- Performance: Font download có thể chậm lần đầu – font cache (`fontCache` Map) trong `generator.ts` đã tồn tại, dùng lại được

## ⚠️ Edge Cases

- **OG disabled** (`settings.seo.og.enabled = false`): runtime handler trả 404
- **Font download timeout**: đã có retry/cache trong `src/og/generator.ts` – không cần thêm
- **Concurrency**: Runtime gen tuần tự (không race condition vì mỗi request gen file riêng)
- **`basePath` setting**: `getOgImagePath()` đã handle `basePath` – dùng lại như hiện tại

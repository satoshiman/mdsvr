# Export Cleanup Plan

## Problem

Khi xóa folder docs cũ, export vẫn render file mới nhưng:
- Folder chứa OG cũ không bị xóa
- Folder chứa HTML cũ không bị xóa

## Root Cause

1. **OG cleanup**: `cleanupOrphanedOG()` chỉ cleanup files trong `ogDir`, không cleanup directory structure
2. **HTML cleanup**: Không có cleanup logic cho HTML files/folders
3. **State location**: `.mdsvr-og-state.json` nằm trong `_html/public/og` thay vì root export folder

## Proposed Solution

### 1. Di chuyển state file sang root export folder

**Current**: `_html/public/og/.mdsvr-og-state.json`

**New**: `_html/.mdsvr-export-state.json`

### 2. Mở rộng state structure để track cả HTML và OG

```typescript
export interface ExportState {
  // HTML pages: urlPath -> { outputPath, sourcePath, hash }
  html: {
    [urlPath: string]: {
      outputPath: string;  // Relative to export dir
      sourcePath: string;  // Relative to root dir
      hash: string;        // sha256 of source file
    };
  };
  
  // OG images: urlPath -> { outputPath, hash }
  og: {
    [urlPath: string]: {
      outputPath: string;  // Relative to export dir
      hash: string;        // sha256 of source file
    };
  };
}
```

### 3. Cleanup logic trước khi render

**Flow**:
1. Load previous state từ `_html/.mdsvr-export-state.json`
2. Scan source files → generate current state (HTML + OG)
3. Compare old vs new state:
   - Tìm orphaned HTML files/folders (trong old nhưng không trong new)
   - Tìm orphaned OG files/folders (trong old nhưng không trong new)
4. Delete orphaned files/folders
5. Render new files
6. Save new state

### 5. Directory cleanup algorithm

```typescript
async function cleanupOrphanedFiles(
  exportDir: string,
  oldState: ExportState,
  newState: ExportState
): Promise<CleanupResult> {
  const deleted: string[] = [];
  
  // Cleanup HTML
  for (const [urlPath, pageState] of Object.entries(oldState.html)) {
    if (!newState.html[urlPath]) {
      // Delete HTML file and parent directory if empty
      const fullPath = path.join(exportDir, pageState.outputPath);
      await fs.unlink(fullPath);
      await cleanupEmptyDir(path.dirname(fullPath), exportDir);
      deleted.push(fullPath);
    }
  }
  
  // Cleanup OG
  for (const [urlPath, ogState] of Object.entries(oldState.og)) {
    if (!newState.og[urlPath]) {
      const fullPath = path.join(exportDir, ogState.outputPath);
      await fs.unlink(fullPath);
      await cleanupEmptyDir(path.dirname(fullPath), exportDir);
      deleted.push(fullPath);
    }
  }
  
  return { deleted };
}

async function cleanupEmptyDir(dir: string, rootDir: string): Promise<void> {
  // Recursively delete empty directories up to rootDir
  while (dir !== rootDir) {
    const entries = await fs.readdir(dir);
    if (entries.length === 0) {
      await fs.rmdir(dir);
      dir = path.dirname(dir);
    } else {
      break;
    }
  }
}
```

# Raw Markdown Feature Plan

## Overview

Add ability to view raw markdown content (unrendered) both at runtime and in export functionality.

## Requirements

- **Runtime**: Add endpoint/route to view raw markdown files
- **Export**: Include raw markdown export option in export functionality

## Implementation Plan

### 1. Runtime Raw Markdown View

- Add new route: `/md/*` to serve markdown files as plain text
- Set proper `Content-Type: text/markdown` or `text/plain` header
- Preserve original markdown formatting without rendering
- Add UI button/link to switch between rendered and raw view
- Handle edge cases:
  - Non-existent files (404)
  - Directory paths (404 or list)
  - Permission issues (403)

### 2. Export Raw Markdown

- Add export option to export markdown files as-is
- Could be:
  - Individual file download
  - Batch export of all markdown files
  - Archive format (zip) containing raw markdown files
- Preserve directory structure in export
- Add UI controls for export options

### 3. UI Integration

- Add "Raw" button/switch on markdown file pages
- Add export controls in existing export UI
- Consider keyboard shortcuts (e.g., `r` for raw view)
- Add visual indicator when in raw mode

### 4. Technical Considerations

- **File serving**: Use existing file system utilities
- **Security**: Ensure only .md files can be viewed as raw
- **Caching**: Consider caching raw content
- **Performance**: Stream large files instead of loading entirely

### 5. Testing

- Test raw view for various markdown files
- Test export functionality
- Test edge cases (empty files, large files, special characters)
- Verify content-type headers
- Test UI integration

## Files to Modify

- Runtime: Add route handler in server files
- Export: Modify export generator/processor
- UI: Add components/controls for raw view and export
- Types: Add any necessary TypeScript types

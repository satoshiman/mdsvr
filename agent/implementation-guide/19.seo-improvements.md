## 2. Implementation Phases

### Phase 1 — Rebase relative internal links (P1)

Mục tiêu: mọi relative `href`/`src` trong rendered HTML được resolve theo
**source file's directory** và emit canonical absolute route — fix ~226 dead
links.

#### Design

`convertMarkdownLinks` hiện pure-string. Đổi signature thành context-aware:

```typescript
type LinkTransformContext = {
  /** Directory URL của source file, vd "/agent-miniapp/01-thiet-ke-he-thong" */
  sourceDirUrlPath: string;
  rootDir: string;
  /** Check file tồn tại trên disk (sync fs.existsSync hoặc pre-built page set) */
  resolveFile: (absSourcePath: string) => "doc" | "asset" | "missing";
};

convertMarkdownLinks(html: string, ctx: LinkTransformContext): {
  html: string;
  warnings: LinkWarning[]; // link resolve ra ngoài docs root / missing
};
```

Quy tắc resolve (áp dụng cho `href` và `src`):

1. External/special (`http`, `//`, `mailto:`, `#anchor`, query-only) → giữ nguyên.
2. Root-relative `/x` → strip `.md`/`.mdx` → normalize canonical (trailing slash
   cho doc route).
3. Relative (`./x`, `../x`, `x`):
   - Join với `sourceDirUrlPath` → candidate absolute route.
   - Resolve sang filesystem path trong `rootDir`: nếu trỏ tới `.md`/`.mdx` (kể
     cả link extensionless mà file `.md` tồn tại) → emit canonical clean route
     (`README`/`index` collapse về directory URL, trailing slash).
   - Nếu trỏ tới asset file (ảnh, pdf, …) → emit absolute asset path dạng
     root-relative.
   - Nếu `resolveFile` = `missing` → giữ nguyên + push warning.
   - Nếu resolve ra ngoài `rootDir` → giữ nguyên + push warning.
4. Anchor/query trên link được rewrite: giữ nguyên suffix (`#h`, `?q=`).

#### Files

- `src/link-transform.ts` — rework thành context-aware; giữ wrapper tương thích
  cho call-site không có context.
- `src/render-page.ts` — truyền `ctx` khi gọi (static mode line 68 và
  cleanUrls mode line 71); `sourceDirUrlPath` suy ra từ `urlPath` của source
  file (bỏ segment filename).
- `src/generators/static-export.ts` — cung cấp `resolveFile` từ page/asset set
  đã scan (tránh stat lặp).
- `src/router.ts` — serve mode `cleanUrls` dùng fs-based `resolveFile`.
- `src/validator/index.ts` — tái sử dụng cùng resolver: thêm/align warning cho
  link resolve ra ngoài docs root và link extensionless → missing file, để
  `--validate-md` bắt lỗi trước export.

#### Notes

- Dynamic serve **không** `cleanUrls` giữ hành vi cũ (`.md` resolve trực tiếp),
  vì URL serve không phải clean-URL directory form — tài liệu hóa khác biệt này.
- Directory listing href (`directory.ts`) xử lý ở Phase 2/3.

#### Tests

Fixture tối thiểu trong `test/` (mới `test/link-transform.test.ts` hoặc mở
rộng `github-source-format.test.ts`):

1. `./sibling` (có và không có `.md`) → `/dir/sibling/`
2. `../other/x.md` → `/other/x/`
3. `./04-x#heading` và `./x.md?y=1` → giữ anchor/query
4. `/absolute/x.md` → `/absolute/x/`
5. `![](../img/a.png)` → absolute asset path, không thêm slash
6. `../../outside-secret.md` → không rewrite + warning
7. Link tới file missing → không rewrite + warning
8. Extensionless `./x` khi `x.md` tồn tại → rewrite; khi không → giữ nguyên
9. Parity: static export và `cleanUrls` serve cho cùng HTML
10. Regression: export `docs-for-test/` — internal link targets 200 = 100%

Mục tiêu: `renderDirectory` trả **body fragment**, không còn nested document;

   theme script/inline breadcrumb. Return fragment:
   `<h1>` + `<nav class="dir-listing">` table (folder 📁/file 📄 rows).

### Phase 4 — `extractFirstParagraph` quality (P3)

Mục tiêu: loại degenerate descriptions (`"Làm gì:"`), giảm fallback
`site.description`, strip hết markdown remnants.

#### Tasks — `src/seo/extract.ts`

1. Bỏ qua label-like lines: line mà sau `cleanInline` kết thúc bằng `:` và
   ngắn (`< 60` chars), hoặc match `/^\*\*[^*]+:\*\*\s*$/` — đây là label đứng
   trước list, không phải prose.
2. Nếu paragraph đầu sau clean `< ~40` chars → **không dừng**, tiếp tục gom
   paragraph kế tiếp (hiện code `break` ở blank line đầu tiên).
3. `cleanInline` bổ sung: `_…_` italic (hiện chỉ strip `*…*`), shorthand
   `[Text]` không có `()` còn sót, HTML comment inline.
4. Giữ contract: soft 160 / hard 200, word-boundary, `null` khi không có
   usable text (để fallback `site.description`).

#### Tests — `test/seo.test.ts`

- `**Làm gì:**` + list → skip sang paragraph sau hoặc null.
- Page mở đầu bằng table/heading → null (fallback) chứ không phải degenerate.
- `_[Stories…]_` và `[Region]-[X]` → plain text sạch.

### Phase 7 — Analytics & site verification (feature request)

Mục tiêu: user cấu hình analytics/verification **một lần** trong
`_mdsvr/settings.json`, generator emit đúng snippet vào `<head>`/`<body>`
trên mọi page — không phải sửa template hay inject thủ công.

#### Design — settings schema

```jsonc
{
  "analytics": {
    // NEW (optional)
    "googleAnalytics": "G-XXXXXXXXXX", // GA4 → gtag.js
    "googleTagManager": "GTM-XXXXXXX", // GTM → head script + noscript iframe
    "clarity": "xxxxxxxxxx", // Microsoft Clarity
    "plausible": {
      // privacy-friendly
      "domain": "docs.example.com",
      "scriptSrc": "https://plausible.io/js/script.js", // optional; self-hosted trỏ về instance riêng
    },
    "umami": {
      "websiteId": "xxxx-xxxx",
      "scriptSrc": "https://cloud.umami.is/script.js",
    },
    "customHead": [
      // raw snippets, append cuối <head>
      "<script>/* provider bất kỳ */</script>",
    ],
  },
  "seo": {
    "verification": {
      // NEW (optional)
      "google": "abc123…", // → google-site-verification
      "bing": "abc123…", // → msvalidate.01
      "yandex": "abc123…", // → yandex-verification
      "pinterest": "abc123…", // → p:domain_verify
      "naver": "abc123…", // → naver-site-verification
    },
  },
}
```

#### Emit rules

- Verification → `<meta name="..." content="...">` trong `<head>` (escape
  attribute values). GSC còn có phương án verify bằng file upload: user đặt
  `googleXXXX.html` vào docs root — export đã copy nguyên file, chỉ cần ghi
  vào docs.
- GA4 → `<script async src="https://www.googletagmanager.com/gtag/js?id=G-…">`
  - inline `gtag('config', …)`; GTM → head script + `<noscript><iframe>`
    **ngay sau** `<body>`; Clarity → inline snippet; Plausible/Umami →
    `<script defer data-domain`/`data-website-id …>`.
- ID format validation: `G-[A-Z0-9]+`, `GTM-[A-Z0-9]+` — warn khi load
  settings, không fail.
- Emit trong **cả serve và export** (zero-config, output nhất quán). Document
  rõ preview local cũng fire hits — user tự filter phía analytics nếu cần.
- `customHead` là raw HTML: hợp lệ dưới trusted-content policy (ADR-0008) vì
  chỉ đọc từ `settings.json` do repo owner kiểm soát — **không** nhận từ
  frontmatter. Ghi rõ trong docs/security section.

#### Files

- `src/settings/schema.ts` — `analytics`, `seo.verification` (Zod, optional).
- Mới `src/template/analytics.ts` — `buildAnalyticsHeadTags(settings)` +
  `buildBodyStartTags(settings)` (GTM noscript); có thể gộp vào
  `template/seo.ts` nếu muốn giữ ít module.
- `src/template/index.ts` — inject head tags (sau SEO block) + body-start.
- `test/analytics.test.ts` hoặc extend `template.test.ts`/`seo.test.ts`.

#### Tests

1. Mỗi provider emit đúng snippet khi cấu hình; không emit gì khi absent.
2. Verification meta đúng `name`/`content` cho từng provider; escaping.
3. GTM noscript đứng ngay sau `<body>`.
4. `customHead` xuất hiện verbatim; invalid ID format → warning, không crash.
5. Serve + export parity (cùng output).

## 3. Backward Compatibility

- `convertMarkdownLinks` signature đổi → internal API, không public; export
  vẫn backward-compatible với docs hiện có (link đúng sẵn không đổi output).
- `renderDirectory` đổi từ full document → fragment: internal; public output
  thay đổi theo hướng fix bug (ghi rõ trong changelog — ai rely vào nested-doc
  markup sẽ thấy khác).
- Trailing-slash hrefs: URLs đích không đổi (301 vẫn phục vụ cả hai form);
  chỉ href emitted đổi.
- `data-code` thay hidden `<pre>`: copy feature giữ nguyên UX; ai scrape
  `.code-block-raw` sẽ break — ghi changelog.
- `seo.noIndexDirectoryPages` default `false` → zero-config không đổi.
- Link warnings: chỉ log, không fail export (trừ khi có option strict sau này).

## 4. Edge Cases

- Link `./README.md` / `./index.md` → collapse về directory canonical `/dir/`.
- Link tới directory không có index (`./sub/` không README) → resolve tới
  auto-index page `/sub/` (tồn tại trong export).
- Anchor-only `#section`, `?query`, `mailto:`, `tel:` → untouched.
- `urlPath` có Unicode/spaces → encode per-segment nhất quán với sitemap.
- MDX pages: transform chạy trên rendered HTML — `href` trong JSX đã qua cùng
  pipeline.
- basePath (GitHub Pages): canonical route là site-relative; `withBasePath`
  áp ở template layer — resolver phải emit route chưa có basePath.
- Symlink/.. escape rootDir → warning, không rewrite.
- Case-insensitive filesystems (macOS): `resolveFile` check cả `.md` lẫn `.mdx`.

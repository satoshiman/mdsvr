# Fix: hljs syntax highlighting CSS không apply

## Bug 1 — `src/renderer/markdown.ts`

`highlight` callback trả về inner HTML thay vì full wrapper, khiến `<code>` không có class `hljs` và CSS selector không match.

```ts
// ❌ Hiện tại
return hljs.highlight(str, { language: lang }).value;

// ✅ Fix — trả về full wrapper
return `<pre><code class="hljs language-${lang}">${
  hljs.highlight(str, { language: lang }).value
}</code></pre>\n`;
```

Làm tương tự trong `renderMarkdownSimple`.

## Bug 2 — `src/template/index.ts`

`lightCss` và `darkCss` được dump thẳng không scope → 2 theme đè nhau, dark luôn thắng.

```ts
// ❌ Hiện tại
return `
:root[data-theme="light"] .hljs { background: var(--code-bg); }
${lightCss}
:root[data-theme="dark"] .hljs { background: var(--code-bg); }
${darkCss}
`;

// ✅ Fix — scope từng theme
function scopeCss(css: string, selector: string): string {
  return css.replace(/(^|\n)(\.hljs)/g, `$1${selector} $2`);
}

return `
${scopeCss(lightCss, ':root[data-theme="light"]')}
:root[data-theme="light"] .hljs { background: var(--code-bg); }

${scopeCss(darkCss, ':root[data-theme="dark"]')}
:root[data-theme="dark"] .hljs { background: var(--code-bg); }
`;
```

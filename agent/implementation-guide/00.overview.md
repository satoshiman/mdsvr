### Legend

- ⏳ **Pending**: Chưa bắt đầu.
- 🔄 **In Progress**: Đang thực hiện.
- ✅ **Completed**: Đã hoàn thành, test pass, ADR cập nhật trạng thái (nếu cần).
- ⏸️ **Blocked**: Bị chặn, cần giải quyết dependency hoặc quyết định khác.

## Hướng dẫn cập nhật

Khi bắt đầu hoặc hoàn thành một phase/task:

1. Sửa trạng thái trong bảng trên.
2. Thêm ngày bắt đầu / hoàn thành.
3. Thêm commit hash vào cột `Commit`.
4. Cập nhật `Cập nhật lần cuối` ở đầu file.
5. Nếu phase hoàn thành và ADR chuyển sang Accepted, cập nhật `architech/02-adr/README.md` và file ADR tương ứng.

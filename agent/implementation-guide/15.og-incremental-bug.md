# OG Incremental Bug

## Problem

Khi export lần đầu (chưa có export-state.json), OG images không được generate. OG folder trống.

## Root Cause

### Bug 1: So sánh hash sai state

**File**: `src/generators/static-export.ts` dòng 595

```typescript
// Check if hash changed by comparing with old state
const oldHash = oldState.html[pageInfo.urlPath]?.hash; // ❌ SAI
```

**Sai ở đâu**: So sánh với `oldState.html` thay vì `oldState.og`

**Đúng phải là**:

```typescript
const oldHash = oldState.og[pageInfo.urlPath]?.hash; // ✅ ĐÚNG
```

**Tại sao sai**:

- Lần đầu export: `oldState.og` = `{}` (empty)
- Nhưng code lại check `oldState.html[pageInfo.urlPath]?.hash`
- HTML hash có thể khác OG hash → logic bị sai
- Khi file source không đổi, OG bị skip dù chưa từng generate

### Bug 2: Khi forceOg=true, currentState.og không được populate

**File**: `src/generators/static-export.ts` dòng 583-612

```typescript
if (!forceOg) {
  // Calculate hash and populate currentState.og
  if (pageInfo.sourcePath) {
    fileHash = await calculateFileHash(pageInfo.sourcePath);
    currentState.og[pageInfo.urlPath] = {
      outputPath: relativeOgPath,
      hash: fileHash,
    };
  }
}
// ❌ Khi forceOg=true, currentState.og KHÔNG được populate
```

**Vấn đề**:

- Khi `forceOg=true`, code nhảy vào `if (shouldGenerate)` ngay
- `currentState.og` không được populate
- Sau khi export, state file sẽ không có OG entries
- Lần export tiếp theo sẽ không có gì để so sánh

## Impact

- **Lần đầu export**: OG không được generate (trống)
- **Export với --force-og**: OG được generate nhưng state không được track
- **Export incremental tiếp theo**: Không biết OG đã tồn tại, có thể generate lại hoặc skip sai

## Fix Required

### Fix 1: Đổi state comparison

**Note**: Sau khi thảo luận, quyết định giữ nguyên `oldState.html` vì OG hash = source hash (cùng track source file)

### Fix 2: Populate currentState.og ngay cả khi forceOg=true

**Applied**: Di chuyển logic populate `currentState.og` ra ngoài check `!forceOg`

### Fix 3: Thêm file existence check

**Applied**: Nếu OG image file không tồn tại → force regenerate

```typescript
// Check if OG image file exists
try {
  await fs.access(ogImagePath);
} catch {
  // File doesn't exist, must generate
  shouldGenerate = true;
}
```

### Fix 4: Di chuyển cleanup sau OG generation

**Applied**: Cleanup chạy sau OG generation để `currentState.og` được populate trước khi so sánh

```typescript
// Move currentState.og population outside the !forceOg check
let fileHash = "";
if (pageInfo.sourcePath) {
  try {
    fileHash = await calculateFileHash(pageInfo.sourcePath);
  } catch {
    fileHash = "";
  }
}

const relativeOgPath = path.relative(outputDir, ogImagePath);
currentState.og[pageInfo.urlPath] = {
  outputPath: relativeOgPath,
  hash: fileHash || "auto-index",
};

// Then check if should generate
if (!forceOg) {
  const oldHash = oldState.og[pageInfo.urlPath]?.hash;
  if (oldHash !== fileHash) {
    shouldGenerate = true;
  }
}
```

3. Export incremental lần 2 → OG không đổi phải được skip

# Claim mdsvr.js.org Subdomain

## Tổng quan

js.org cung cấp free subdomain `*.js.org` cho các JS ecosystem projects (npm packages, JS tools).  
Sau khi hoàn thành: site sẽ live tại **`https://mdsvr.js.org`** thay vì `satoshiman.github.io/mdsvr`.

---

## Bước 1 — Fork repo js-org/js.org

Truy cập: **https://github.com/js-org/js.org**

Click nút **Fork** (góc trên phải) → Fork về account `satoshiman`.

---

## Bước 2 — Chỉnh sửa file `cnames_active.js`

Trong fork của bạn, mở file:

```
cnames_active.js
```

Tìm vị trí theo **alphabet** (chữ `m`, gần `markdown`, `menu`, v.v.), thêm 1 dòng:

```js
"mdsvr": "satoshiman.github.io/mdsvr",
```

> **Lưu ý format**: mỗi entry là `"subdomain": "github-pages-url"`, không có `https://`, không có trailing slash.

Ví dụ đoạn xung quanh trông sẽ như này:

```js
...
"mdn": "mdn.github.io",
"mdsvr": "satoshiman.github.io/mdsvr",
"menu": "...",
...
```

Commit thẳng trên GitHub UI với message:

```
Add mdsvr.js.org
```

---

## Bước 3 — Tạo Pull Request

Truy cập fork của bạn → Click **"Contribute"** → **"Open pull request"**

- **Title**: `Add mdsvr.js.org`
- **Description**:

```
## New subdomain request

- Subdomain: `mdsvr.js.org`
- Target: `satoshiman.github.io/mdsvr`
- Project: mdsvr — zero config Markdown documentation server
- npm: https://www.npmjs.com/package/mdsvr
- GitHub: https://github.com/satoshiman/mdsvr

mdsvr is a Node.js npm package that serves Markdown/MDX files as a
full-featured documentation website with zero configuration.
```

Submit PR → **chờ review**.

---

## Bước 4 — Sau khi PR được merge (làm SAU, không làm trước)

Chỉ thực hiện các bước này **sau khi PR được approve và merge**:

### 4a. Thêm CNAME vào gh-pages branch

```bash
echo "mdsvr.js.org" > gh-pages/CNAME
git add gh-pages/CNAME
git commit -m "chore: add CNAME for mdsvr.js.org"
git push origin main
git subtree push --prefix gh-pages origin gh-pages
```

### 4b. Set custom domain trong GitHub Pages Settings

1. Vào **https://github.com/satoshiman/mdsvr/settings/pages**
2. Mục **Custom domain**: nhập `mdsvr.js.org` → **Save**
3. Tick **Enforce HTTPS**

### 4c. Verify

Sau ~5-10 phút: **https://mdsvr.js.org** sẽ live.

---

## Lưu ý quan trọng

- **KHÔNG** thêm CNAME trước khi PR merge — site sẽ bị broken
- PR thường được review trong vòng **24-48 giờ**
- Nếu có naming conflict, maintainer sẽ comment trên PR
- Content requirement: site phải liên quan đến JS ecosystem (mdsvr là npm package → ✅)

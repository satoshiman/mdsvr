# Interactive Quiz Blocks

> Thêm tính năng quiz tương tác: LLM/tác giả viết quiz dưới dạng fenced block ` ```quiz `
> chứa JSON có kèm đáp án; UI ẩn đáp án, chấm điểm phía client và lưu thống kê
> per-user bằng localStorage.

---

## Decisions đã chốt

- **Authoring format**: fenced code block ` ```quiz ` chứa JSON (giống cơ chế
  ` ```mermaid `). Hoạt động trong cả `.md` và `.mdx`.
- **Stats scope**: local per-user (localStorage). Không cần backend; hoạt động
  cả ở static export. Server-side aggregate stats là future enhancement.
- **Question types v1** (core 4): `single`, `multiple`, `true-false`, `self-check`.

---

## Overview

Hiện tại quiz trong docs là markdown thuần: section "Questions" + section "Answers"
trong callout (xem `mdsvr-course-generator` skill, `lesson-templates.md` §6).
Tính năng này chuyển quiz thành khối tương tác:

- Đáp án + explanation được embed trong HTML nhưng **ẩn** — chỉ hiện sau khi user
  chọn đáp án và bấm "Kiểm tra".
- Panel kết quả hiển thị score (`8/10 — 80%`) + lịch sử lượt làm từ localStorage.
- Format JSON ổn định, có zod schema → LLM sinh được một cách đáng tin, và
  `--validate-md` check được schema ngay khi viết docs.

## Authoring format (LLM-facing contract)

````markdown
```quiz
{
  "id": "asyncio-basics",
  "title": "Kiểm tra nhanh",
  "mode": "exam",
  "questions": [
    {
      "type": "single",
      "question": "Hàm nào là entrypoint chuẩn để chạy một coroutine?",
      "options": ["`asyncio.run()`", "`asyncio.exec()`", "`asyncio.start()`"],
      "answer": 0,
      "explanation": "`asyncio.run()` là high-level API được khuyên dùng từ Python 3.7."
    },
    {
      "type": "multiple",
      "question": "Những phát biểu nào đúng về `asyncio.gather()`?",
      "options": ["Chạy đồng thời các awaitable", "Luôn chạy trên nhiều thread", "Trả về list kết quả theo thứ tự"],
      "answer": [0, 2]
    },
    {
      "type": "true-false",
      "question": "`async`/`await` là cú pháp riêng của thư viện asyncio.",
      "answer": false,
      "explanation": "`async`/`await` là cú pháp ngôn ngữ; asyncio chỉ là một consumer."
    },
    {
      "type": "self-check",
      "question": "Tự giải thích event loop hoạt động như thế nào.",
      "answer": "Event loop là vòng lặp trung tâm: nó lấy task từ queue, chạy cho tới khi gặp `await` rồi nhường quyền điều khiển cho task khác."
    }
  ]
}
```
````

### Quiz-level fields

| Field   | Type                   | Default   | Mô tả                                                                                                                                 |
| ------- | ---------------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `id`    | `string`               | auto-hash | Định danh ổn định cho localStorage stats. Khi thiếu: `q-<hash(payload)>`. Đổi payload → đổi hash → stats reset (documented behavior). |
| `title` | `string`               | `"Quiz"`  | Tiêu đề hiển thị trên header.                                                                                                         |
| `mode`  | `"exam" \| "practice"` | `"exam"`  | `exam`: chọn hết rồi bấm "Kiểm tra" một lần. `practice`: mỗi câu có nút check riêng, feedback tức thì.                                |

### Question schema (discriminated union trên `type`)

| Type         | Fields bắt buộc                      | `answer`                                 | UI                                        |
| ------------ | ------------------------------------ | ---------------------------------------- | ----------------------------------------- |
| `single`     | `question`, `options` (≥2), `answer` | `number` (index vào options)             | radio                                     |
| `multiple`   | `question`, `options` (≥2), `answer` | `number[]` (non-empty)                   | checkbox                                  |
| `true-false` | `question`, `answer`                 | `boolean`                                | 2 nút Đúng/Sai                            |
| `self-check` | `question`, `answer`                 | `string` (model answer, inline markdown) | nút "Xem đáp án" + tự chấm Đúng/Chưa đúng |

- `explanation: string` optional trên mọi type — inline markdown, hiện sau khi check.
- `question`, `options[]`, `answer` (self-check), `explanation` đều render qua
  **inline markdown** (bold/code/link) với `html: false` — không cho raw HTML.
- Scoring: all-or-nothing mỗi câu (multiple phải chọn đúng hết, không thiếu không thừa).
  `self-check` tính vào mẫu số, do user tự report đúng/sai. Partial credit → phase 2.

## Implementation

### 1. Quiz module — `src/renderer/quiz.ts` (NEW)

Single source of truth cho schema + HTML rendering, dùng chung bởi markdown-it
và MDX paths.

```typescript
import { z } from "zod";

const BaseQuestion = z.object({
  question: z.string().min(1),
  explanation: z.string().optional(),
});

const SingleQuestion = BaseQuestion.extend({
  type: z.literal("single"),
  options: z.array(z.string()).min(2),
  answer: z.number().int().nonnegative(),
});

const MultipleQuestion = BaseQuestion.extend({
  type: z.literal("multiple"),
  options: z.array(z.string()).min(2),
  answer: z.array(z.number().int().nonnegative()).min(1),
});

const TrueFalseQuestion = BaseQuestion.extend({
  type: z.literal("true-false"),
  answer: z.boolean(),
});

const SelfCheckQuestion = BaseQuestion.extend({
  type: z.literal("self-check"),
  answer: z.string().min(1),
});

export const QuizSchema = z.object({
  id: z.string().optional(),
  title: z.string().optional(),
  mode: z.enum(["exam", "practice"]).default("exam"),
  questions: z
    .array(
      z.discriminatedUnion("type", [
        SingleQuestion,
        MultipleQuestion,
        TrueFalseQuestion,
        SelfCheckQuestion,
      ]),
    )
    .min(1),
});

export type Quiz = z.infer<typeof QuizSchema>;
```

**Key functions**:

- `parseQuiz(json: string): { quiz?: Quiz; error?: string }` — `JSON.parse` +
  `QuizSchema.safeParse`; trả message gộp từ zod issues. Refine thêm: `answer`
  index phải `< options.length`.
- `renderQuizBlock(json: string): string` — parse → HTML. Input invalid → render
  `<div class="quiz quiz-error">` dạng callout-danger hiển thị lỗi cho tác giả
  (không throw — giống triết lý validator báo lỗi thay vì crash render).
- `quizHash(payload)` — FNV-1a/sha1 ngắn trên normalized JSON cho auto `id`.
- `renderQuizInline(text)` — inline markdown cho question/option/explanation.
  Dùng `MarkdownIt({ html: false, linkify: true })` riêng, `md.renderInline()`.
  Math ($...$) optional phase 2.

**Emitted HTML** (server-rendered, progressive enhancement — đọc được khi JS off):

```html
<div class="quiz" data-quiz-id="asyncio-basics" data-quiz-mode="exam">
  <div class="quiz-header">
    <span class="quiz-title">Kiểm tra nhanh</span>
    <span class="quiz-progress">0/4</span>
  </div>

  <div class="quiz-question" data-qtype="single" data-answer="0">
    <div class="quiz-question-text">...<code>asyncio.run()</code>...</div>
    <div class="quiz-options">
      <label class="quiz-option"
        ><input type="radio" name="quiz-<id>-q0" /> <span>...</span></label
      >
      <!-- radio cho single; checkbox cho multiple; input name unique per quiz+question -->
    </div>
    <div class="quiz-explanation" hidden>...</div>
  </div>

  <div class="quiz-question" data-qtype="true-false" data-answer="false">
    <div class="quiz-question-text">...</div>
    <div class="quiz-options">
      <label class="quiz-option"
        ><input type="radio" name="quiz-<id>-q2" value="true" />
        <span>Đúng</span></label
      >
      <label class="quiz-option"
        ><input type="radio" name="quiz-<id>-q2" value="false" />
        <span>Sai</span></label
      >
    </div>
  </div>

  <div class="quiz-question" data-qtype="self-check">
    <div class="quiz-question-text">...</div>
    <button type="button" class="quiz-reveal">Xem đáp án</button>
    <div class="quiz-model-answer" hidden>...</div>
    <div class="quiz-self-mark" hidden>
      <button type="button" data-mark="correct">Tôi trả lời đúng</button>
      <button type="button" data-mark="incorrect">Chưa đúng</button>
    </div>
  </div>

  <div class="quiz-actions">
    <button type="button" class="quiz-check">Kiểm tra đáp án</button>

```

Đáp án nằm trong `data-answer` (index / comma-joined indices / `"true"|"false"`).
Đây là self-study quiz — user view-source là thấy đáp án; document rõ là
honor-system, không phải secure assessment.

Escaping: mọi text render qua inline-md (`html:false`) hoặc `escapeHtml`; không
nhúng raw JSON vào attribute → không cần `data-quiz` blob.

### 2. Markdown-it hook — `src/renderer/markdown.ts` (EDIT)


cần sửa gì thêm.

### 3. MDX support — `src/renderer/mdx.ts` + `components.tsx` (EDIT)

`.mdx` đi qua MDX compiler, không qua markdown-it → cần remark plugin nhỏ:

```typescript
// remarkQuiz: transform code[lang=quiz] → mdxJsxFlowElement <Quiz source="...">
// Trong mdx.ts remarkPlugins array, sau remarkFrontmatter.
function remarkQuiz() {
  return (tree) => {
    visit(tree, "code", (node) => {
      if (node.lang !== "quiz") return;
      // đổi node thành:
      // { type:'mdxJsxFlowElement', name:'Quiz',
      //   attributes:[{type:'mdxJsxAttribute', name:'source', value: node.value}] }
    });
  };
}
```

String attribute value mang JSON nguyên văn — compiler escape đúng khi emit
`jsx(Quiz, {source: "..."})`, không bị vấn đề quote-nesting như children text.

`Quiz` component trong `components.tsx` — thin wrapper dùng chung renderer:

```tsx
export function Quiz({ source }: { source: string }) {
  return <div dangerouslySetInnerHTML={{ __html: renderQuizBlock(source) }} />;
}
```

Register vào `builtinComponents` → tự động nằm dưới toggle
`settings.mdx.components.Quiz` (ADR-0008 trust model: HTML do chính renderer
sinh ra, không phải user HTML thô). Cũng cho phép tác giả `.mdx` viết trực tiếp
`<Quiz source="..."/>`.

### 4. Client-side interactivity — `src/template/index.ts` (EDIT)

`initQuizzes()` mới, register trong cả 2 nhánh DOMContentLoaded/readyState hiện có
(cùng chỗ với `initTableToolbars()`). Vanilla JS, không framework:

- **Select**: change listener trên `input` → update `.quiz-progress` (`answered/total`).
- **Check** (`.quiz-check`, exam mode): duyệt `.quiz-question`, so selection với
  `data-answer`:
  - `single`/`true-false`: một option đúng.
  - `multiple`: set equality trên indices đã check.
  - `self-check`: đọc `data-mark` user đã bấm (bắt buộc reveal + self-mark trước
    khi được tính điểm; nếu chưa mark → câu đó tính "chưa trả lời").
  - Đúng → `.quiz-option.correct` + `✓`; sai → tô `.incorrect` trên lựa chọn sai
    và `.correct` lên đáp án đúng. Unhide `.quiz-explanation`.
- **Practice mode**: mỗi `.quiz-question` có nút check riêng (`data-quiz-mode="practice"`),
  disable options sau khi check.
- **Reset**: clear inputs, classes, `hidden` states, result panel.
- **Result panel** (`.quiz-result`): `Đúng 8/10 — 80%` + breakdown theo type +
  dòng history: `Best: 9/10 · 3 lượt làm`.

**localStorage stats** (per-user, không backend):

```
key:   "mdsvr-quiz:<quizId>"
value: { "attempts": 3, "best": 9, "last": 8, "total": 10, "lastAt": 1759600000 }
```

Ghi khi bấm Check (exam) hoặc khi đã check hết câu (practice). Đọc lúc init để
hiển thị `Best` ngay trên header nếu đã từng làm.

## Behaviors đáng lưu ý

- **Search index**: `stripMarkdown()` đã bỏ ``` blocks → JSON quiz không lọt vào
  search index (đáp án không leak, câu hỏi cũng không search được — tradeoff chấp
  nhận được, note trong docs).
- **Static export parity**: render + chấm hoàn toàn client-side → export y hệt
  dynamic serve, không branch nào thêm.
- **llms.txt**: quiz JSON vẫn nằm trong raw markdown corpus — LLM consumers đọc
  được câu hỏi lẫn đáp án (fine, format máy-đọc được là mục tiêu).
- **No-JS**: câu hỏi + options vẫn đọc được như form thường; nút Check không làm
  gì. Progressive enhancement, giống hiện trạng table/mermaid toolbars.

## Tests — `test/quiz.test.ts`

- `QuizSchema`: accept 4 types; reject missing/invalid fields; reject `answer`
  index ≥ `options.length`; `mode` default `"exam"`.
- `renderQuizBlock`: valid payload → `.quiz` div đúng `data-quiz-id`, `hidden`
  trên explanation; options có `name` unique per question; escaping (`<script>`
  trong question bị neutralize bởi `html:false` + renderInline).
- Invalid JSON / schema → `.quiz-error` markup chứa message, không throw.
- `renderMarkdown` integration: ` ```quiz ` → `.quiz` HTML trong output;
  fenced block không bị hljs wrap.
- `renderMdx`: ` ```quiz ` trong `.mdx` → `.quiz` markup; `Quiz: false` trong
  settings → không transform.
- Validator: file chứa quiz JSON lỗi → `invalid-quiz` error với đúng line.
- Chạy: `npm test` (đã build sẵn `dist-test`).

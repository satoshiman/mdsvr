# Features

mdsvr comes with everything you need for modern documentation sites:

## SEO & Sharing

| Feature | Description             | Link         |
| ------- | ----------------------- | ------------ |
| **SEO** | Meta tags, sitemap, RSS | [seo](./seo) |

## Why These Features?

Every feature in mdsvr is:

- **Zero-config by default** — works out of the box
- **Opt-in customization** — configure when you need to
- **Performance-focused** — no bloat, fast loading
